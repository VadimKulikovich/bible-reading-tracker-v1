## Navigation

The application currently uses simplified navigation without user authentication:

- Selecting **Log In** on the landing page navigates to the home page, where the interactive calendar and reading progress tracking features are available.
- Selecting **Log Out** on the home page returns the user to the landing page.

## Current Functionality

- Interactive calendar
- Daily reading progress tracking
- Morning and evening progress tracking
- Browser-based data persistence using Local Storage

## Planned Enhancements

The next development phase will focus on expanding the application's functionality and introducing backend capabilities:

- User registration and authentication
- Backend development and database integration
- Persistent user accounts and reading data
- Expanded reading management functionality
